## 細部功能規劃與實作規格

### 一、帳號登入與金鑰機制 (Account Login & Key Setup)

#### 1. 金鑰輸入與建立存檔 (`KeySetupModal`)
- **入口機制**：
  - 進入頁面時，先檢查 `localStorage.getItem("shenma_player_key")`。
  - 若不存在任何金鑰：開啟 `KeySetupModal`，玩家可選擇：
    1. **輸入自訂金鑰**（如 `eric_sanguo`）：連線 GAS 讀取，若存在則載入；若不存在則建立新存檔（預設 5 名初始名將、1000 世界金幣、1 級主公）。
    2. **訪客一鍵體驗**：自動生成 `guest_${Date.now().toString(36)}`，並於本地建立完整初始存檔，支援後續在設定中綁定金鑰。
- **切換金鑰 (Switch Key)**：
  - 在「玩家資訊」或「設定」視窗中，可輸入新金鑰切換帳號。
  - 切換前自動將舊存檔未保存的修改寫入本機與伺服器。

#### 2. 存檔狀態資料結構 (`PlayerState`)
```ts
export interface PlayerHeroState {
  hero_id: string;
  level: number;
  star: number;
  atk: number;
  def: number;
  hp: number;
}

export interface TeamSlot {
  slot: number;      // 0 ~ 4
  hero_id: string;
}

export interface PlayerState {
  key: string;            // 帳號金鑰
  nickname: string;       // 主公暱稱
  level: number;          // 主公等級 (1 ~ 100)
  exp: number;            // 當前經驗值
  gold: number;           // 世界點數/金幣 (用於武將升級)
  capacity: number;       // 隊伍出陣容量上限 (隨等級增加)
  max_stage: string;      // 最高通關關卡 ID (例如 "chapter1_1")
  cleared_stages: Record<string, number>; // 通關星級 { "chapter1_1": 3 }
  heroes: PlayerHeroState[]; // 擁有的所有武將等級與屬性
  team: TeamSlot[];       // 5 個出征槽位
  serverRev: number;      // 雲端版本號 (樂觀鎖)
}
```

#### 3. 雙層快取與非同步同步機制 (`useJsPlayerStore`)
- **本機快取**：
  - 讀取優先序：`sessionStorage` → `localStorage` → GAS 雲端 `get_profile`。
  - 達成**0 延遲秒開即玩**，同時在背景觸發靜默雲端更新。
- **自動保存 (Debounce 30s)**：
  - 玩家進行「隊伍調整」、「升級武將」、「修改暱稱」後，立即更新本機快取，並啟動 30 秒倒數計時器批次送出 GAS `save_profile`。
  - 若在戰鬥勝利結算，則立即觸發結算保存，不等待 debounce。
- **離線相容**：
  - 若網路中斷或 GAS 回應超時，自動切換至「本機離線模式」，所有養成與戰鬥進度均保存在本機 `localStorage`，待網路恢復時提示同步。

### 二、主公資產頂欄 (Player Top Bar & HUD)

在原先的戰鬥畫面上方，新增**三國古風高質感主公頂欄**：
- **主公頭像與暱稱**：點擊開啟「玩家資訊視窗」(`PlayerInfoModal`)。
- **主公等級與 EXP**：顯示 `Lv.{level}` 與精緻經驗條（滑鼠懸停顯示 `{exp} / {maxExp}`）。
- **世界金幣**：顯示 `🪙 {gold}`（與戰場內 5000 局內軍資金幣清楚區隔）。
- **同步狀態燈**：
  - 🟢 已同步 (Synced)
  - 🔵 同步中 (Syncing...)
  - 🟡 待同步 (Pending 30s)
  - ⚪ 離線模式 (Offline)
- **快捷操作按鈕**：
  - ⚔️ **隊伍編排**（開啟 `TeamEditModal`）
  - 📜 **名將錄與升級**（開啟 `HeroRosterModal`）
  - ⚙️ **系統設定**（開啟 `SettingsModal`）

### 三、隊伍編排系統 (5-Slot Team Management)

- **出征槽位**：固定 5 個出征席次（Slot 1 ~ 5）。
- **容量上限 (Cost Limit)**：
  - 每個武將有其出陣 Cost（例如 10~25 點）。
  - 隊伍總 Cost 不得超過主公的 `capacity`（升級主公可提高容量上限）。
- **戰鬥聯動限制**：
  - **核心規則**：進入戰鬥時，地圖上的道路與高台部署選單（`PlacementMenuModal`），**嚴格只顯示出征隊伍內的 5 位武將**，不再把全名錄 13 隻傾巢而出！
  - 武將一旦在戰場上陣，顯示「已上陣」並禁止重複放置。

### 四、武將名錄與養成升級 (Hero Roster & Progression)

- **名將展示**：
  - 依職業（步兵、弓兵、砲兵、騎兵、法師）分類篩選。
  - 展示基礎數值與目前加成數值（Lv、ATK、DEF、HP、射程、攻速、技能介紹、對空標籤）。
- **世界金幣升級**：
  - 升級費用公式：`upgradeCost = baseCost * currentLevel`。
  - 點擊升級，扣除主公世界金幣，武將等級 +1，攻擊/防禦/生命依成長率增加。
  - 戰場實戰直接讀取武將養成後的實體屬性！

### 五、關卡進度、解鎖與戰鬥結算獎勵

1. **關卡解鎖**：
   - 關卡選擇器中，未達通關條件的關卡呈現上鎖狀態（🔒），滑鼠懸停提示「需先通關上一關」。
   - 已通關關卡顯示獲得星數（⭐⭐⭐）。
2. **戰鬥結算**：
   - 勝利時計算大本營殘餘 HP：
     - 滿血 (20/20) → 3 星評價
     - HP ≥ 10 → 2 星評價
     - HP < 10 → 1 星評價
   - 發放獎勵：
     - 主公經驗值 EXP（例如第 1 關 100 EXP）
     - 世界金幣（例如第 1 關 200 金幣）
     - 若為最新關卡，將 `max_stage` 推進至下一關！
   - 主公升級檢驗：經驗達到門檻，主公升級，隊伍容量 Capacity +5，跳出升級祝賀動畫。
   - 即時保存至存檔，並送出雲端更新。

### 六、系統設定與備份 (Settings & Backup)

- **音效與音樂**：
  - BGM 音量滑桿 (0% ~ 100%)。
  - SFX 音量滑桿 (0% ~ 100%)。
- **存檔備份**：
  - 「匯出存檔」：一鍵下載 `shenma_save_{key}_{timestamp}.json`。
  - 「匯入存檔」：可上傳 JSON 存檔檔案進行恢復。
  - 「切換金鑰 / 登出」：返回金鑰登入介面。
