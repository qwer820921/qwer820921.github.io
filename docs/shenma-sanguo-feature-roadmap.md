## 3. 已實作的技能

### 首擊加倍：馬超「衝鋒」（第一版；原本綁在趙雲，改綁已提交 `d94ebe70`）

| 項目     | 內容                                                                                                                                                                                                                                                                                              |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 依據     | 正式設定表 `heroes_config` 的馬超被動描述「衝鋒：首擊傷害翻倍」。這個機制在第一版綁在趙雲（名稱「奇襲」），趙雲的描述是「閃避率提升15%」，所以改綁到馬超；甘寧的描述「奇襲：首擊必殺」意思還沒決定，沒有借用這個機制                                                                              |
| 規則     | 每場戰鬥中，馬超第一次命中敵人的普通攻擊造成 2 倍傷害，之後恢復普通攻擊（攻擊力 100：第一擊 200，之後 100）。倍率交給既有的傷害計算，沒有改敵人減傷或其他武將                                                                                                                                     |
| 何時用掉 | 只有真的對有效目標發出攻擊才用掉；沒有目標（例如備戰中）不會用掉                                                                                                                                                                                                                                  |
