## 3. 已實作的技能

### 趙雲「奇襲」（Round 12，第一版）

| 項目     | 內容                                                                                                                                                                                          |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 規則     | 每場戰鬥中，趙雲第一次命中敵人的普通攻擊造成 2 倍傷害，之後恢復普通攻擊（攻擊力 100：第一擊 200，之後 100）。倍率交給既有的傷害計算，沒有改敵人減傷或其他武將                                 |
| 何時用掉 | 只有真的對有效目標發出攻擊才用掉；沒有目標（例如備戰中）不會用掉                                                                                                                              |
| 何時重置 | 同一場戰鬥裡，換波次、移動位置、更新隊伍或屬性、移除後重新放置都不會再觸發；切換關卡或同一關重來（新的 `battle_id`）才重置                                                                    |
| 範圍     | 主頁與獨立戰鬥頁都有效；其他武將與塔不變                                                                                                                                                      |
| 規則來源 | Web 的 `utils/heroSkills.ts` 是唯一來源：武將列表／詳情的說明文字，和隨出征資料 `team_list[].skill` 送進 Godot 的參數（`first_strike`、倍率 2）都由它產生；Godot 不認得的技能一律當作普通攻擊 |
| 存檔     | 技能是戰場效果，不寫進玩家存檔，也沒有改 GAS／Sheets 的結構                                                                                                                                   |
| 畫面     | 武將列表顯示「技能：奇襲」，詳情顯示完整規則；觸發時趙雲上方出現放大的金色「x2!」（Godot 專案沒有中文字型，畫布裡的中文會顯示成方框，所以不用「奇襲」兩個字），敵人頭上的傷害數字是 2 倍      |
| 驗證     | Godot 測試 R12-1～R12-9（用敵人血量變化斷言實際傷害）、反向驗證、瀏覽器 `r12-web.js`；結果見基準文件 §20                                                                                      |

| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

| 規則來源 | Web 的 `utils/heroSkills.ts`：列表／詳情的說明、詳情裡的實際射程（`effectiveRange`），和送進 Godot 的參數（`{ id: "long_range", range_multiplier: 1.5 }`）都由它產生。每種技能只帶自己的參數；Godot 不認得的技能 id 一律當作普通攻擊 |

### 周瑜「火攻」（Round 15，第一版）

正式設定（Codex 2026-09-28 唯讀讀取 `get_heroes_config`，沒有玩家金鑰、沒有寫入）：`hero_id=zhou_yu`、`job=mage`、橘色、花費 9、基礎攻擊 122、射程 4、射程成長 0.05、攻擊間隔 1 秒；設定裡的 `passive`「火攻：持續燒傷」只是說明文字，效果由這次的程式實作。

| 項目     | 內容                                                                                                                                                                                                                                                                                                                  |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 規則     | 每次有效普通攻擊命中後，對該敵人附加灼燒：之後每 1 秒一次、共 3 次，每次是命中當下攻擊力的 20%；第一次在附加後 1 秒（命中當下不另外跳）。攻擊力 100、沒有減傷時：普通一擊 100，停止攻擊後依序 20、20、20。普通攻擊的傷害、射程與攻擊間隔不變。數值是 Round 15 選定的第一版設計值，還沒做過平衡                        |
| 刷新     | 同一個敵人只有一份灼燒，不疊層、不另開計時器。再次命中時剩餘跳數回到 3、每跳傷害換成這次命中的攻擊力，已在倒數的下一跳時間不重設（快速連打也會每秒跳一次）；所以不保證刷新後正好再持續三整秒                                                                                                                          |
| 停止     | 敵人離開射程、周瑜被移除後，已附加的灼燒仍會跳完；敵人死亡、抵達基地或被移除時立即停止；新的一場沒有殘留。時間用遊戲時間推進：暫停時不前進、恢復後繼續，時間倍率（部署選單的子彈時間等）照比例                                                                                                                        |
| 結算     | 灼燒走敵人既有的受傷／死亡流程，擊殺、戰鬥金幣、清波只觸發一次；灼燒本身不會再觸發火攻。沒有範圍傳染、指揮光環或泛用 Buff 框架                                                                                                                                                                                        |
| 規則來源 | Web 的 `utils/heroSkills.ts`：列表／詳情的說明、每跳傷害（`burnTickDamage`）和送進 Godot 的參數（`{ id: "burn", burn_ratio: 0.2, burn_ticks: 3, burn_interval: 1 }`）都由它產生。Godot 的 `Hero.gd` 命中後呼叫 `Enemy.apply_burn`，灼燒記在敵人身上（`Enemy.gd`）；不認得的技能 id 一律普通攻擊                       |
| 畫面     | 武將列表顯示「技能：火攻」；詳情寫出規則與目前攻擊力下每次灼燒的傷害（例如「目前攻擊力 122：每次灼燒 24.4」）。戰場上灼燒中的敵人有橘色外圈，跳傷數字是橘色（Godot 沒有中文字型，不顯示文字）                                                                                                                         |
| 存檔     | 技能與敵人的灼燒狀態只在戰場；存檔、session、`save_result` 維持原本的欄位，沒有改 GAS／Sheets                                                                                                                                                                                                                         |
| 驗證     | Godot 測試 R15-0～R15-12（Round 16 起用物理時鐘，不用牆鐘；R15-12 是固定步進；用每一幀的實際血量與時間：首次延遲、3 跳、連續命中不疊加不延後、快照更新、灼燒打倒只結算一次、抵達基地、移除武將、新的一場、暫停、時間倍率、不認得的技能）、反向驗證、瀏覽器 `r15-web.js`（主頁實際部署、兩個入口）；結果見基準文件 §23 |

### 關羽「橫掃」（第一版，已提交 `3e1506d6`）

| 項目     | 內容                                                                                                                                                                                                                                                                                                    |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 規則     | 每次有效普通攻擊命中後，以主目標被打中時的位置為中心、半徑 1 格內（含邊界），最多 2 名其他仍存活的敵人各受這一擊傷害的 50%；主目標的傷害不變。範圍內超過 2 名時由近到遠，距離相同時先生成的敵人優先（`Enemy.spawn_seq`）；每個敵人最多被橫掃一次。數值是第一版的暫定值，尚未做平衡                      |
